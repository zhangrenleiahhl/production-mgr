  发货 / 排产 / 物料 系统 · 云端同步配置说明
══════════════════════════════════════════════════════════

想让「电脑」和「手机」数据互通、随时随地都能用，按下面 4 步做。
全部免费，只需一个邮箱注册 Supabase 账号。

────────────────────────────────────────────────────────────
第 1 步：注册 Supabase（免费）
────────────────────────────────────────────────────────────
1. 打开 https://supabase.com ，点 "Start your project"（用邮箱注册，免费）。
2. 登录后点 "New project"，填项目名（如 生产管理），设一个数据库密码，
   地区选最近的（如 Singapore），点 Create。
3. 等约 1 分钟项目建好。

────────────────────────────────────────────────────────────
第 2 步：建数据表（只需一次）
────────────────────────────────────────────────────────────
1. 左侧菜单 → SQL Editor → New query。
2. 把同目录文件《supabase-schema.sql》里的全部内容粘进去，点 Run。
   （会建一张 app_data 表，用于存所有同步数据。）

────────────────────────────────────────────────────────────
第 3 步：拿到两个值，填进配置文件
────────────────────────────────────────────────────────────
1. 左侧菜单 → Project Settings → API。
2. 复制两样东西：
   - Project URL        （形如 https://xxxx.supabase.co）
   - anon public key    （以 eyJ 开头的一长串）
3. 用记事本打开同目录的《cloud-config.js》，把里面两行占位改成你的值：
       url: "https://你的ProjectURL",
       key: "你的anonKey"
   保存即可。

────────────────────────────────────────────────────────────
第 4 步：用起来
────────────────────────────────────────────────────────────
• 电脑：双击《生产管理客户端.html》（或三个页面之一）即可，顶部导航出现
  「☁ 拉取最新 / 已同步」状态。
• 手机：把这三个 html 连同 cloud-config.js、cloud-sync.js 一起放到任意能
  访问的网址（或用「生产管理客户端」里打开页面后「添加到主屏幕」），
  手机浏览器打开同一网址，数据自动和电脑同步。
• 任一端改动 → 约 1 秒自动上传云端；点「☁ 拉取最新」可立即下载另一端的新数据。

══════════════════════════════════════════════════════════
  常见问题
══════════════════════════════════════════════════════════
Q：没填配置能用吗？
A：能。没配置时自动降级成本地存储（各设备各自存），和以前一样。

Q：数据会不会丢？
A：云端有一份，本地也有一份。建议仍定期用客户端的「💾 数据备份」导出 JSON 留底。

Q：多人同时改会冲突吗？
A：本版是"最后保存覆盖"，适合单人/小团队。多人高频并发编辑请后续升级账号体系。

Q：数据安全吗？
A：数据存在你自己的 Supabase 项目里，可随时导出/删除。anon key 是公开设计，
   仅适合内部使用；若要严格管控，可后续在 Supabase 加访问密码或登录。

Q：手机怎么最方便打开？
A：把整套文件部署到一个免费静态托管（如 GitHub Pages / Netlify / Vercel），
   得到一个网址，手机直接访问；或在手机浏览器打开页面后「添加到主屏幕」，
   就像 App 一样点开。
