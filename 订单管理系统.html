导入方式
🏬

立库库存导入

读取 SAP 货载报表，按「描述」自动汇总各型号总数，写入对应型号的立库库存

① 选择报表文件 （货载报表 .xls / .xlsx / .csv）
📄 点击选择报表文件 或把文件拖到这里
也可用 Ctrl+V 直接粘贴 Excel 区域
② 匹配与写入方式
③ 解析预览 （确认无误后再导入）
选择文件后，这里会实时显示匹配结果
匹配规则：报表「描述」列 → 系统「型号」，依次尝试 ① 描述整串等于型号 → ② 描述首个下划线前的简称等于型号 → ③ 型号包含于描述 → ④ 型号以描述开头 → ⑤ 仍不中则用规格型号再试一次。
数量：同一描述的多行明细（不同托盘/批次）自动求和；只统计单位为「件」的行（KG、片、M 等非件数物料默认排除，可取消勾选）。
未匹配的物料会被跳过，导入后可点「导出未匹配清单」导出核对。
🌏

南区库库存导入

读取实时库存报表，按「规格型号（物料编码）」精确匹配系统型号，汇总各型号可用总数，写入对应型号的南区库库存

① 选择报表文件 （实时库存 .xls / .xlsx / .csv）
📄 点击选择报表文件 或把文件拖到这里
也可用 Ctrl+V 直接粘贴 Excel 区域
② 数量口径与写入方式
取数列 实时库存报表含「可用/不可用/库内/库外/正在移动/全部」六组数量，默认取可用总数
③ 解析预览 （确认无误后再导入）
选择文件后，这里会实时显示匹配结果
匹配规则：优先用报表「规格型号」列的物料编码与系统「物料编码」精确匹配；匹配不到时改用「描述」→ 系统「型号」，依次尝试 ① 描述整串等于型号 → ② 名称+材质+工艺+图号组合唯一命中 → ③ 名称+工艺唯一命中。
数量：同一物料的多行明细（不同批号）自动求和，取所选口径列；单位为「件 / PC / 个」才计入，KG 等重量单位默认排除。
未匹配的物料会被跳过，导入后可点「导出未匹配清单」导出核对。
🏗

后处理库库存导入

读取货载列表，按「规格型号（物料编码）」精确匹配系统型号，自动汇总各型号数量，写入对应型号的后处理库库存

① 选择报表文件 （货载列表 .xls / .xlsx / .csv）
📄 点击选择报表文件 或把文件拖到这里
也可用 Ctrl+V 直接粘贴 Excel 区域
② 匹配与写入方式
③ 状态筛选 （只统计在后处理流程中的物料）
④ 解析预览 （确认无误后再导入）
选择文件后，这里会实时显示匹配结果
匹配规则：优先用报表「规格型号」列的物料编码与系统「物料编码」精确匹配；匹配不到时改用「描述」→ 系统「型号」，依次尝试 ① 描述整串等于型号 → ② 描述首个下划线前的简称等于型号 → ③ 型号包含于描述 → ④ 型号以描述开头 → ⑤ 名称+材质+工艺+图号组合唯一命中。
数量：同一物料的多行明细（不同容器/批次）自动求和；单位为「件 / PC / 个」才计入，KG 等重量单位默认排除。
未匹配的物料会被跳过，导入后可点「导出未匹配清单」导出核对。
🗄

SAP库库存导入

读取 SAP 库存报表（EXPORT.XLSX），按「物料」编码精确匹配系统型号，汇总各工厂 / 存储地点 / 批次的非限制使用的库存，写入对应型号的 SAP 库库存

① 选择报表文件 （支持真正的 .xlsx / 伪 Excel .xls / .csv）
📄 点击选择 EXPORT.XLSX 或把文件拖到这里
也可用 Ctrl+V 直接粘贴 Excel 区域作为兜底
② 数量口径与写入方式
取数列 SAP 报表含多组库存数量，默认取非限制使用的库存
③ 解析预览 （确认无误后再导入）
选择文件后，这里会实时显示匹配结果
XLSX 解析：浏览器直接解压读取，不上传任何文件、不依赖网络或外部库。
匹配规则：优先用报表「物料」列编码与系统「物料编码」精确匹配；同一编码对应多个型号时用「物料描述」消歧，仍不唯一则判为未匹配（宁可跳过也不写错）。匹配不到时依次尝试描述整串、名称+材质+工艺+图号组合。
数量：同一物料在多工厂 / 存储地点 / 批次的多行明细自动求和，取所选口径列；单位为「件 / PC / 个」才计入，KG 等重量单位默认排除。
未匹配的物料会被跳过，导入后可点「导出未匹配清单」导出核对。
